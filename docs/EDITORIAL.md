# Editorial and theological review

Canonical roles:
- CONTRIBUTOR — submits material;
- INTAKE_EDITOR — accepts and classifies submissions;
- CORPUS_EDITOR — structures Work/Passage and metadata;
- SOURCE_REVIEWER — validates attribution, locator and provenance;
- THEOLOGICAL_REVIEWER — reviews theological classification/links;
- PUBLISHER — publishes approved graph material;
- ADMIN — operational administration.

Roles can be global or scoped to a Corpus through PersonEditorialRole.

EditorialDecision is append-oriented: corrections and later review decisions do not erase prior decisions. Published material can be superseded by a new reviewed version/link rather than silently rewritten.

The editorial pipeline is:

`Submission -> Intake -> Classification -> Extraction -> Fragmentation -> Linking -> Review -> TheologicalReview -> Publication -> Corrections/Versions`

Rights remain a separate gate. Editorial approval does not grant copyright permission.
