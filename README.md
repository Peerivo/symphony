# Peerivo Symphony / Симфония

«Симфония» — provenance-first корпус Писания, толкований, Предания, вопросов и межконфессиональных/межрелигиозных разборов.

## Каноническая модель

- Scripture → Book → Chapter → Verse.
- Work → WorkSection хранит полные произведения и адресуемые фрагменты.
- Interpretation связывает конкретный фрагмент источника со стихом/темой/тезисом.
- Question — постоянная сущность графа, а не одноразовый поисковый запрос.
- Claim/Position фиксирует конкретное утверждение и его provenance.
- Tradition/School/Author/Source позволяют не приписывать одной религии единственное «мнение».
- «Путь истины» — блок внутри Симфонии: Question/Claim → связанные стихи → толкования → позиции → возражения → первоисточники.
- PopularitySignal агрегирует анонимизированные запросы и помогает поднимать частые вопросы на страницах стихов.

## Хранилище

Основная БД: PostgreSQL (в production — Supabase Postgres) + pgvector. Полнотекстовый поиск сначала PostgreSQL FTS/trigram; отдельный поисковый движок добавляется только после измерения корпуса/нагрузки. Полные оригинальные документы и медиа — object storage; в Postgres — нормализованный текст, адресуемые фрагменты, связи, provenance, права и поисковые индексы.

Не нужен отдельный graph DB на старте: связи моделируются таблицами PostgreSQL и recursive CTE. Это сохраняет одну source-of-truth БД и позволяет позже построить materialized graph/search projections.

## Ingestion

Каждый импорт проходит Source → Fetch/Import → Raw snapshot → Parse → Work/Sections → Claims/Interpretations → Links → Search index.

Никакой источник не считается разрешённым для массового зеркалирования только потому, что он публично доступен. Для каждого Source обязательны rights_status, license/permission evidence, canonical URL, fetched_at, checksum и parser version. Полные труды импортируем, когда они public domain либо имеется достаточное разрешение/лицензия; иначе храним допустимые метаданные/ссылки/фрагменты.

«Азбука веры» — приоритетный кандидат на seed-корпус, но массовое копирование запускается только после фиксации прав/условий использования.

## M1

Первый milestone: схема корпуса + ingestion contract + один легальный seed-source + поиск «стих / приблизительная цитата / вопрос / мне сказали, что…» + страница стиха с «Главное по этому месту» и «Путь истины».
